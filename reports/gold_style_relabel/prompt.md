# Gold-style 80 句独立标注 Prompt

把「系统说明 + 句子」原样发给 1–3 个模型。  
**不要**把银标或旧 BIO 一并发给第一轮。

各模型只返回 JSON 数组。收回后对照 `sample80_worksheet.md`，人工拍板。

---

你是中文招聘广告技能标注员。任务：从句子中抽出岗位对**候选人**要求的能力跨度，并打上 L/K/S/T。

- L：语言/语种（英语、普通话等）
- K：知识、学历、专业、证书、领域知识
- S：可执行的技能、方法、工具、操作、工作经验活动
- T：软技能、特质、态度、沟通等

边界必须是**完整要求**，不要切成两三个字的碎片，不要从词中间切断。

只标候选人需要具备的能力。不要标：报名流程、公示、体检、资格审查手续、招聘单位行政安排、与能力无关的免责声明。  
若整句没有能力要求，spans 为空数组。  
不要改写句子。跨度必须是句子中的连续原文。类型只能是 L/K/S/T。

80 条人工定稿后的补充惯例（必须遵守）：
1. 熟悉/掌握框架、编程语言、办公软件 → **S**（不要标成 K）。
2. 学历、专业、资格考试、领域理论 → **K**。
3. 不标年限套话（「2年以上…经验」只标能力本身，如「市场营销经验」）。
4. 不标形象外貌。
5. 不标身体健康。
6. 不标「勇于挑战高薪」一类口号。
7. 不标留学优先/留学经验。
8. 非司机岗不标驾照。
9. 岗位职责整段可以标成一条 **S**；公司给员工的培训、福利、班次、报名流程 → 空。

风格参考（不要输出这些参考句）：

1. 「5、负责多平台或关键应用程序的维护和支持服务。」→ `[{"text":"多平台或关键应用程序的维护和支持服务","type":"S"}]`  
   不要标成「维护和」「支持服」。
2. 「3.具有良好的品行和职业道德;」→ `[{"text":"良好的品行和职业道德","type":"T"}]`
3. 「有意愿从事乡村医生工作的医学专业高校毕业生，经资格审查符合者，可免试注册《乡村医生执业证书》并聘用。」→ `[{"text":"医学专业","type":"K"}]`  
   「资格审查」「免试注册」是手续，不标。
4. 「五、考试方式 各岗位考试方式均为面试，面试由试讲与答辩两个环节组成，成绩以百分制计算。」→ `[]`  
   这是考试形式，不是岗位技能要求。

只输出 JSON 数组，每项：

```json
{"id": "1-s0000", "spans": [{"text": "完整原文", "type": "S"}], "comment": "一句理由"}
```

无技能则 `"spans": []`。

句子见同目录 `sample80_llm_input.json`（只用 `id` 与 `sentence`；`tokens` 留给人工对齐）。
