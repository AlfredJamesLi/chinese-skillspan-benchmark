# LSKT v4 操作性定义（银标 / 训练用）

保留中文 **LSKT 四类**。对齐 Zhang 的是切跨度的方法（短、完整、Skill vs Knowledge 语义），不是把标签改成两类。

| 标签 | 含义 | 评测投影到 Zhang |
|---|---|---|
| L | 语种 | → KNOWLEDGE |
| K | 学历、专业、证书、领域知识 | → KNOWLEDGE |
| S | 工具、方法、可执行职业技能 | → SKILL |
| T | 软技能、特质 | → SKILL |

1. 连续原文；禁止 `支持服` 半词切断。  
2. 短而独立，优先 2–8 字：`Python`、`计算机专业`、`沟通能力`。不要整段职责一条 S。  
3. 熟悉/掌握/精通只标对象。并列拆开。  
4. 报名/体检/公示/福利/鸡汤 → 空句。  
5. 平坦不重叠（与现 Gold 一致）。Zhang 式重叠以后再说。
