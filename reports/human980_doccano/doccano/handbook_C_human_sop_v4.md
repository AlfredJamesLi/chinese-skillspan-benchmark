## 跨度规则（必须）

1. 跨度是句中**连续原文**。不要改写、不要补字。[Z22] [D18]  
2. **禁止半词**：不要 `支持服`、`操作系统的问`、`培训其`。[本协议]  
3. **唯一切段：语义不变则尽量短**（优先 2–8 字）。不要一整段职责收成一条 S。废止「能不拆就不拆」。**[本协议]**  
4. 顿号/逗号/「和、与、或」连接的**独立**能力 → **各自一条**。[Z22] 拆开会漂类型才留一条。[本协议]  
5. 「熟悉 / 掌握 / 了解 / 精通 / 具备 / 具有」**只标后面的对象**，不标这些动词。[Z22] [本协议]  
6. 编程语言、框架、办公软件、具体工具**不是固定一类**：运用/岗位工具 → 光杆名 **S**；课程/原理/基础/语法 → **整段知识短语 K**；看不出 → **S** 并写不确定。[EQF] [本协议]  
7. 语种名、语言水平、语言考试（大学英语六级 / CET-6 / 日语N2）→ **L**。ISO / OCJP 等技术或职业认证 → **K**。L 既是知识也是能力，故单独列支，不并进 K。[ESCO-L] [本协议]  
8. 平坦、不重叠。一条跨度一个类型。不要嵌套。[TKS02] [本协议] 嵌套是另一项任务 [FM09] [Yu20]。L–K–S–T **不是**优先级；禁止 `L＞S＞K＞T`。[ESCO14] [Z22] [AP08] 拿不准标 **S** 并记日志 [Z22]。`本科及以上学历` **K** [Z22] [ESCO-Q]。`沟通管理` / `客户汇报` **T** [ESCO-T]。  
8b. 潜在同界/嵌套/交叉：能拆就拆；否则只留完整能力，备选写入裁决日志。不要猜。[AP08] [Z22] 详见手册 B 重叠附录。  
9. 不标：形象外貌、身体健康、年限数字本身（只留能力）、非司机岗驾照、留学优先套话。[Z22] [本协议]  
10. 「××能力」两步：领域依赖 → S；可迁移 → T。禁止「能做事→S」。`科研能力` 默认 T。[ESCO-T] [ONET] [本协议]  
11. `网络` / `安全` / `ICT` 三语境；「保证/确保」不进跨度；`工作经验` 不标；`大项目售前经验` → `大项目售前` S。[本协议]

## 空句（`spans: []`）

整句没有对候选人的能力要求 → 全部不标。[Z22] [本协议] 默认空：

- 事业单位**流程**：报名、资格审查、笔试面试时间、准考证、体检、公示、咨询电话、岗位代码、招聘人数。  
- **福利/班次**：五险一金、带薪年假、包吃住、加班费、节日福利、班次、地点。  
- 鸡汤、公司简介、工位家具、弹性上班时刻表。  
- **应届生/校招**特有：实习期长短、户口/档案、三方协议、开题答辩时间、仅「欢迎应届生」而无能力短语。

`empty_hint` 只是提示，不是命令。句中若有明确能力短语，仍要标。
