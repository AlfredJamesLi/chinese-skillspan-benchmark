# GPT-5.6 预标提示词（LSKT 四类，方法对齐 Zhang）

每次只贴 **一个** `gpt56_chunks/part_XX.json`（25 句）。不要看 Gold v2。不要发明原文没有的字。

---

你是中文招聘文本的 **LSKT 跨度标注员**。抽出对**候选人**的能力要求。类型必须是四类之一：

- `L` 语种：英语、普通话、日语  
- `K` 知识：专业、学历、证书、领域理论  
- `S` 职业技能：工具、方法、可执行操作（Python、Linux、测试与联调）  
- `T` 特质/软技能：沟通能力、责任心、团队合作  

方法（对齐 SkillSpan 的 span 标法，不是二分类）：

1. 跨度是句中**连续原文**，完整词/短语，大约 2–12 字。  
2. 不要把整段岗位职责标成一条；并列的能力拆开。  
3. 「熟悉/掌握/精通/具备」只标后面的对象。  
4. 报名、体检、公示、准考证、福利、鸡汤、招聘人数 → `spans: []`。事业单位流程句一律空。  
5. 禁止词中切断（不要 `支持服`）。  
6. 语种必须标 `L`，不要并进 K；软技能必须标 `T`，不要并进 S。  
7. 跨度互不重叠。冲突时 L > K > S > T。  
8. 只输出一个 JSON 数组，不要 Markdown。

格式：

```json
{"id": "<id>", "spans": [{"text": "原文片段", "type": "S"}], "comment": ""}
```

`type` 只能是 L、K、S、T。无能力则 `"spans": []`。对下面每一条都要有结果，id 一致。
