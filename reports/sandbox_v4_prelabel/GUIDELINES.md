# LSKT 标注规范（方法对齐 Zhang，类型仍为四类）

**类型体系不变：LSKT。**  
对齐 Mike Zhang 的是 **怎么标跨度**（原文 span、完整提及、不标非能力句、先银标再人工），不是把四类收成 Skill/Knowledge。

评测时可以 **额外** 投影：`L+K → KNOWLEDGE`，`S+T → SKILL`（已有投影审计）。主标和 Doccano 仍打 **L / K / S / T**。

Gold v2 冻结，本规范用于沙盒预标 + 日后 Doccano，不覆盖论文 Gold。

---

## 一、类型定义（保留中文 LSKT）

| 标签 | 英文对照（Zhang 投影） | 标什么 | 中文例子 |
|---|---|---|---|
| **L** | → KNOWLEDGE | 语种、方言、语言能力 | 英语、普通话、日语、英文读写能力 |
| **K** | → KNOWLEDGE | 学历、专业、证书、领域知识 | 计算机相关专业、本科、CET-6、数据结构、飞控系统 |
| **S** | → SKILL | 可执行职业技能、工具、方法、平台 | Python、Linux、交换机配置、测试与联调、需求分析 |
| **T** | → SKILL（软技能） | 特质、态度、可迁移软技能 | 沟通能力、责任心、团队合作、抗压能力 |

Zhang SkillSpan 把硬技能/软技能和 knowledge 分开，且允许 skill 与 knowledge **重叠**。我们 **保持平坦、互不重叠**（一个字只属一类）：这是中文 CRF / 现有 scorer 的约束，也是中文特有选择。冲突时优先级：**L > K > S > T**（语种先于专业，专业/证书先于会做，会做先于性格）。

---

## 二、对齐 Zhang 的「标法」（不是改类型）

1. **Span 级、原文连续子串**，不标 ESCO ID，不改写句子。  
2. **标能力提及，不标整句职责。** 「负责…；完成…」里只抽出其中的技能/知识短语。  
3. **完整提及，禁止词中切断。** 不要 `支持服`、`技术支`、`普通话表`。  
4. **并列拆开。** `英语` `Python` `沟通能力` 三条；同一名词短语内的并列修饰（维护和支持服务）可合一条。  
5. **非能力句留空。** 流程、福利、鸡汤、人数、地点-only → `spans: []`。

---

## 三、中文特有规则（Zhang 英文 JD 没有、必须保留）

1. **无空格。** 跨度按字/连续 ASCII 对齐原文；不要按英文空格切。  
2. **事业单位招聘公告。** 报名、资格审查、笔试面试时间、准考证、体检、公示、咨询电话、岗位代码、招聘人数 → 空。不要把「资格复审所需材料」标成 K。  
3. **「熟悉 / 掌握 / 了解 / 精通 / 具备 / 具有」只标宾语。**  
   - `熟悉 Linux` → `Linux`（S）  
   - `掌握英语` → `英语`（L）  
   - `具备沟通能力` → `沟通能力`（T）  
   - `计算机相关专业` → 整段专业名（K），不要只标「计算机」  
4. **语种单独为 L**，不要并进 K（这是相对 Zhang 的中文保留：普通话/英语在招聘里极常见且政策相关）。  
5. **软技能单独为 T**，不要并进 S（沟通、责任心、吃苦耐劳）。工具和「会做」才是 S。  
6. **专业 vs 技能：** `X专业` / `X学历` / 资格证 → K；`会 X` / 工具名 / 操作名 → S。  
7. **不标：** 年限、形象、身体健康、挑战高薪、非司机岗驾照、公司给员工的培训福利。

---

## 四、粒度（在 LSKT 下向 Zhang 靠拢）

目标：**短而完整的能力短语**，大约 2–12 字，中位接近 Gold v2 的 4 字，不要 extra-long 整段条款（以前 human80 均值 17.9 那种不要）。

| 要 | 不要 |
|---|---|
| `沟通能力`（T） | 整句「具有良好的沟通协调能力及团队精神」一条 T |
| `Python`（S）、`英语`（L） | `支持服` 切断 |
| `计算机相关专业`（K） | 把「负责无人机飞控系统技术项目开发策划、总体方案论证」整段标 S |
| 空句：体检禁食 8 小时 | 硬标「体检」为 S |

同一句多种类型共存、**不重叠**：`精通英语和 Python，沟通能力强` → L `英语`、S `Python`、T `沟通能力`。

---

## 五、五个例子

**1** `熟悉 Linux 与 Python，英语四级及以上。`  
→ S `Linux`；S `Python`；L `英语`；K `四级`（若原文是「英语四级」且分不开，可整段 L 或 K 一条，优先切出 `英语`（L）+ `四级`（K）若连续则 `英语四级` 标 L 或拆不开时标 K——**能拆则拆：英语=L，四级=K**）

更干净：`英语`（L）、`四级`（K）、`Linux`（S）、`Python`（S）。

**2** `计算机相关专业，本科及以上学历，有责任心。`  
→ K `计算机相关专业`；K `本科`；T `责任心`。

**3** `负责交换机的配置；`  
→ S `交换机的配置`（或 `交换机`+`配置` 若你希望更原子：优先一条完整 NP `交换机的配置`）。

**4** `报考人员须按公告要求报名，咨询电话 12345。`  
→ `spans: []`

**5** `具备良好沟通能力和团队协作精神，精通普通话。`  
→ T `沟通能力`；T `团队协作精神`；L `普通话`。

## 六、输出格式（GPT / Cursor / 日后写回）

```json
{"id": "1801-s0002", "spans": [{"text": "自动驾驶仪", "type": "K"}, {"text": "测试与联调", "type": "S"}], "comment": ""}
```

`type` ∈ `{L,K,S,T}`。无能力：`"spans": []`。

Doccano 序列标注标签名：**L / K / S / T**（不要 `SILVER_` 前缀）。
