# Chinese-SkillSpan manuscript source

Main document: 0main.tex. Compiler: XeLaTeX. Bibliography processor: BibTeX.
Run XeLaTeX, BibTeX, then XeLaTeX twice, or until cross-references settle.
The supplied 0main.bbl contains the compiled bibliography. Keep the directory
structure intact. Standard TeX-distribution packages and TeX Gyre Termes are needed.

The archive includes the manuscript and appendices, 49 cited references, eight vector
figures, and the document class and bibliography style. Bundled CJK font subsets and
their licences are included. Table_01.tex through Table_24.tex are standalone editable
table exports; compile them from the archive root using XeLaTeX. Their shared support
files are included. Research data and code are available through the repositories
identified in the manuscript.
