\subsection{Shared-Guideline Evaluation against the Human Reference}
\label{sec:gold150-shared-r7}
The shared protocol evaluates six configurations on all 150 reference sentences, using V4.2.12-based general instructions and five schematic examples. The system prompt, examples, and checksum manifest are included in the \href{https://doi.org/10.5281/zenodo.22851581}{Qwen reproduction archive}. For this check, we applied Unicode Normalization Form KC (NFKC), which treats compatible forms such as full-width and half-width letters alike, and removed whitespace. None of the five complete examples matched a reference sentence or appeared in full within one. This comparison checks text overlap; it does not establish that earlier protocol choices were made independently of the reference set.

Each response identifies the sentence and gives each span as its literal text, zero-based occurrence index, and L/K/S/T type. The parser converts these spans to Unicode offsets for exact and relaxed scoring against the unchanged reference texts.

Qwen adaptation uses the fixed settings described under Training and Inference. The API configurations share task instructions but use the output budgets listed in Table~\ref{tab:model-identity}.

For the XLM-R-large and ESCOXLM-R comparison, tokenizer placeholders retain whitespace and other source positions that would otherwise be discarded. Labels are attached to each original character's first subword, and predictions cover all chunks, including the final remainder. Scoring uses the original text and Unicode-code-point offsets.

\paragraph{Span parsing and matching.}
After mapping spans to source offsets, the parser orders candidates by start offset and original output order. It keeps the first compatible candidate and rejects duplicates, conflicting types at the same boundary, and overlaps. Partial responses retain valid spans; fully rejected or malformed responses yield empty predictions. All input sentences are scored.

Exact matching deduplicates identical span tuples within each sentence. Relaxed matching traverses reference spans in source order and selects the unused same-type prediction with highest IoU, taking the first prediction on a tie. This greedy matching uses an IoU threshold of 0.5. A sentence contributes no span counts when both its prediction and reference contain no spans. The released \href{https://github.com/AlfredJamesLi/chinese-skillspan-benchmark/blob/e3f0aa87f65cdfcb399b0c9f305bb7666a76d3b6/scorer/score_lskt.py}{scorer}, \href{https://github.com/AlfredJamesLi/chinese-skillspan-benchmark/blob/e3f0aa87f65cdfcb399b0c9f305bb7666a76d3b6/scripts/eval_gold150_ext.py}{evaluation script}, and \href{https://github.com/AlfredJamesLi/chinese-skillspan-benchmark/tree/main/reproduction/reviewer_revision_20261005}{output audit} provide the implementation and response counts. In the DeepSeek thinking run, 18 requests exhausted the output budget before a final answer. These responses count as empty predictions; all 150 reference sentences remain. Scores thus include failure to complete within that budget.

\paragraph{Run variability and paired bootstrap intervals.}
For configurations repeated across three training seeds, we report the mean and sample standard deviation.

To account for dependence among sentences from the same source document, we grouped the 150 reference sentences into 61 document groups. Each of 10,000 paired bootstrap draws samples 61 complete groups with replacement and includes all their sentences. The same draw is used for all compared models and each fixed training seed; micro-F1 is recomputed before seed means and paired differences are calculated. Table~\ref{tab:core-paired} reports percentile intervals. The intervals account for within-document dependence and are conditional on the reference set and fitted models. They are unadjusted for multiple comparisons. Training-seed SD separately measures variation across training runs. As a sensitivity check, widening the bootstrap intervals for the six displayed comparisons using Bonferroni tail probabilities does not change which intervals include zero; detailed intervals and code are provided in the supplementary calculations.

\paragraph{Mismatch examples.}
\label{sec:error-examples}
The two examples in the Results section use Qwen predictions without an adapter under the shared prompt. Sentence IDs identify the source sentences in the released reference set. The first example (sentence ID: \texttt{1801-s0004}) is \zh{（4）负责参与公司无人机飞控系统技术项目开发策划、总体方案论证、技术设计} (responsible for participating in technical project development planning, overall design assessment, and technical design for the company's unmanned aerial vehicle flight-control system). The predicted S span is \zh{参与公司无人机飞控系统技术项目开发策划} at $[5,24)$; the overlapping reference S span is \zh{技术项目开发策划} at $[16,24)$. Their IoU is $8/19<0.5$, so the pair fails both exact and relaxed typed matching.

\Needspace{4\baselineskip}
The second example (sentence ID: \texttt{1802-s0005}) is \zh{6、培训其他方法、工具和技术支持多个应用。} (approximate gloss: training in other methods, tools, and techniques to support multiple applications). Both layers select \zh{方法} (method) at $[6,8)$, with predicted type S and reference type K. Offsets are zero-based, half-open Unicode-code-point intervals. The second response also contains two span candidates rejected because their occurrence indices could not be resolved in the source sentence. Both examples use the existing reference annotations.
