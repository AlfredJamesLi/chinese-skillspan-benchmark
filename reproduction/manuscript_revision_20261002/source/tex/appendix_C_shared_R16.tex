\subsection{Shared-Guideline Evaluation against the Human Reference}
\label{sec:gold150-shared-r7}
The shared protocol evaluates six configurations on all 150 reference sentences, using V4.2.12-based general instructions and five schematic examples. The system prompt, examples, and checksum manifest are included in the \href{https://doi.org/10.5281/zenodo.22851581}{Qwen reproduction archive}.

Table~\ref{tab:model-identity} lists the model configurations, access routes, and output budgets. Request dates, response identifiers, and completion metadata are available in the \href{https://github.com/AlfredJamesLi/chinese-skillspan-benchmark/tree/main/reproduction/style_revision_20261005}{reproduction notes}.

Models return an ID and spans as literal \texttt{text}, zero-based \texttt{occurrence}, and L/K/S/T \texttt{type}. The span parser resolves spans to Unicode offsets for exact and relaxed scoring with the released span scorer. All input texts match the human reference set.

Qwen adaptation is evaluated with fixed inference settings, as specified in the main implementation section. The API configurations share task instructions but use the output budgets listed in Table~\ref{tab:model-identity}.

\paragraph{Span parsing and matching.}
The parser resolves literal spans to source offsets, sorts candidates by start offset and original output order, and keeps the first compatible candidate. Later duplicates, same-boundary type conflicts, and overlaps are rejected. Partial responses retain accepted spans; fully rejected or malformed responses become empty predictions. All supplied sentences are included in scoring.

Exact matching deduplicates identical span tuples within each sentence. Relaxed matching traverses reference spans in source order and selects the unused same-type prediction with highest IoU, taking the first prediction on a tie. This greedy matching uses an IoU threshold of 0.5. Empty--empty records contribute no span counts. The public \href{https://github.com/AlfredJamesLi/chinese-skillspan-benchmark/blob/e3f0aa87f65cdfcb399b0c9f305bb7666a76d3b6/scorer/score_lskt.py}{span scorer implementation} and \href{https://github.com/AlfredJamesLi/chinese-skillspan-benchmark/blob/e3f0aa87f65cdfcb399b0c9f305bb7666a76d3b6/scripts/eval_gold150_ext.py}{human-reference evaluation entry point} document the executable scoring procedure. The \href{https://github.com/AlfredJamesLi/chinese-skillspan-benchmark/tree/main/reproduction/reviewer_revision_20261005}{completion and parser audit} documents output-status counts. In the DeepSeek thinking run, 18 requests exhausted the output budget before producing a final answer. These responses are scored as empty predictions, with all 150 reference sentences retained. The resulting score includes completion failure under that budget.

\paragraph{Paired bootstrap intervals.}
To allow dependence among sentences with the same source identifier, we grouped the 150 reference sentences by the prefix preceding \texttt{-s}, giving 61 groups. Each of 10,000 paired bootstrap draws samples 61 complete groups with replacement and includes all their sentences. The same draw is used for all compared models and each fixed training seed; micro-F1 is recomputed before seed means and paired differences are calculated. Table~\ref{tab:core-paired} reports percentile intervals. These prefixes match the source-document identifiers in the original corpus. The intervals account for within-document dependence and are conditional on the reference set and fitted models. They are unadjusted for multiple comparisons. Training-seed SD separately measures variation across training runs. As a sensitivity check, widening the bootstrap intervals for the six displayed comparisons using Bonferroni tail probabilities leaves all inclusion/exclusion-of-zero conclusions unchanged; detailed intervals and code are in the supplementary calculations.

\paragraph{Mismatch examples.}
The two examples in the Results section use Qwen predictions without an adapter under the shared prompt. For \texttt{1801-s0004}, the complete sentence is \zh{（4）负责参与公司无人机飞控系统技术项目开发策划、总体方案论证、技术设计} (responsible for participating in technical project development planning, overall design assessment, and technical design for the company's unmanned aerial vehicle flight-control system). The illustrated prediction is S at $[5,24)$ and the overlapping reference is S at $[16,24)$; their IoU is $8/19<0.5$.

For \texttt{1802-s0005}, the complete sentence is \zh{6、培训其他方法、工具和技术支持多个应用。} (approximate gloss: training in other methods, tools, and techniques to support multiple applications). Both layers select \zh{方法} (method) at $[6,8)$, with predicted type S and reference type K. Offsets are zero-based, half-open Unicode-code-point intervals. The second response also contains two rejected occurrence references. Both examples use the existing reference annotations.
