\section{Discussion}
\label{sec:discussion}

Silver supervision improved Qwen's end-to-end extraction under matched inference conditions. All three adapters raised F1 across the K, S, and T types and recall in each of the three reference-span length bins (Table~\ref{tab:external-chinese}; Figure~\ref{fig:qwen-diagnostics}). The adapters also produced fewer responses with rejected span candidates, so the scores reflect span extraction and output validity together. These results support using silver labels to adapt a model to this annotation task. JobBERT-zh + CRF had a slightly higher mean F1 than Qwen + LoRA in the main silver-supervised comparison, although their training and inference settings differed.

Aggregate scores do not show where extraction fails. The gap between exact and relaxed F1 indicates how sensitive the results are to boundary matching. Sentence examples show whether an error is a boundary mismatch or a type disagreement (\hyperref[sec:extraction-diagnostics]{Extraction Diagnostics}). For this reason we report exact, relaxed, and boundary-only scores together, and character offsets let readers find each disagreement in the source text.

A single-seed comparison of expanded silver pools (Table~\ref{tab:expanded-silver-main}) adds a caution. The configuration that scored higher on its own silver test did not score higher on the shared human reference. This is a descriptive observation from one run, so it does not establish a ranking across training runs. The silver tests differ in both texts and annotations, whereas the human reference is \mbox{a shared evaluation target.}

The human reference concentrates on ambiguous cases that came up during handbook development, so the type-level results should be read with this in mind. K combines knowledge with qualifications and industry background, and the human reference contains only two L spans, so L results rest on very few cases. Reference sentences were kept out of Qwen and encoder supervision, but 59 of the 61 source-document groups identified from reference record IDs also occur in the 2,150-record silver training set (\hyperref[app:d]{Appendix D}). Scores for models trained on this set may therefore overstate performance on unseen documents. JobBERT-zh's original pretraining corpus was unavailable, so its overlap with the human reference could not be checked (\hyperref[app:d]{Appendix D}). Independent annotation of new documents would broaden the evaluation across requirement types and recruitment contexts. The annotations describe advertised requirements. Using them to assess individuals would require separate evidence of validity and fairness.

\section{Conclusions}
\label{sec:conclusion}

Chinese-SkillSpan is a benchmark for identifying competency spans and assigning their types in Chinese job advertisements. It combines source-text annotations with character-level offsets, an ESCO-informed handbook, separate human reference and silver labels, and shared scoring procedures. In a small blinded study, agreement on span boundaries alone was slightly higher than agreement that also required types, although \mbox{the confidence intervals overlap.}

With inference settings fixed, silver-label adaptation improved Qwen's end-to-end extraction over the unadapted model. A prompted GPT model ranked highest among the configurations evaluated, but its lead was not clear-cut. The released annotations, handbook, JobBERT-zh checkpoints, predictions, and scoring code allow others to compare new systems \mbox{against the same targets.}

Two extensions remain. Mapping spans to ESCO concepts, which \citet{zhang2022skillspan} also leave to future work, would connect the benchmark to the wider taxonomy. Allowing overlapping type layers would test whether a single flat type loses information in ambiguous cases, and it would need scoring that accepts more than one valid type for a span.
