\subsection{Matched Qwen Frozen-Prediction Diagnostics}
\label{sec:qwen-diagnostics-r2}
Diagnostics reuse the same 150 reference sentences and each run's frozen accepted spans. Typed exact matching is completed on each full sentence before aggregation by gold-span length. Bins ($\leq4$, 5--8, $\geq9$ Unicode code points) are fixed in advance; they contain 346/243/74 gold spans in 102/110/56 sentences, respectively. A sentence may contribute gold spans to multiple bins. Type-specific unmatched predictions count as FP even in empty-reference sentences. Each seed is evaluated separately on the same test set. Whole-set exact F1 agrees with each archived full-precision result.
