# 版本差异与适用范围

本包是待试运行的公开 API 版，不是旧数据的原始生成程序。版本号 silver_public_api_v1.0。

## 保留的规则
保留 L/K/S/T、范围先于类型、连续原文、无损拆分、Unicode 码点偏移、项目经验规则、语境判型和待裁决门槛。类型待决时的临时 S 规则仍保留，相关记录不得自动作为最终监督标签。

## 表达与结构整理
- 2026-09-13 措辞修订：将固定类型排序的否定表述改为依据语义及局部上下文判型；明确暂标 S 仅为待裁决占位值。未改变标签体系或待裁决处理规则。本版尚未运行，仍保留 v1.0，更新文件校验值。
- 移除“本轮用户确认”“未经批准不得执行”等历史任务语句和本地项目号。
- 将口语化措辞规范化；将历史审批和数据保护说明移至 README。
- E01–E05 对应原例 130、134、128、185、102。E03–E05 补充现有输入文件中的完整原文；E04 展开“前段六项知识”。示例是选定规则说明，不是整句完整标签答案。
- 不添加 V4.2.14 的后续规则。本文规则基础仍为 v4.2.12。

## 属于执行协议变化的项目（不能称为纯文字润色）
- 持续 Codex 对话改为无历史的独立 API 请求；只传 id/text，不传旧标签、来源队列或实验划分。
- 原输出为原记录 JSONL，并修改 gpt6_* 四字段；新输出为结构化 JSON 对象，分离 spans/status/note/issues，原始来源字段在调用端保留。
- 原 note 中的 candidate_complete 加 confirmed_empty 标记，改为三个互斥状态。
- 模型自报移除；requested_model、response_model 和路由说明由调用端记录。
- 本版让 API 返回跨度文本与数值偏移；历史流程包含语义跨度选择后由程序序列化偏移。新流程需试跑核验偏移错误，不宣称与旧输出等价。
- 新版不要求外部会话或隐式手册上下文。若后续增加完整手册、例子、重试纠错或改成 text/occurrence 表示，需升版并冻结新的完整请求。

旧记录保持原版本标记。新 API 数据保留独立批次与协议字段，不追溯改写旧 2,451 条。
