## 最小对照

**P0-SFT vs P1-SFT：** 相同数据 / 起点 / 种子 42·43·44 / 超参 / 选模，计划中的唯一改动是提示词（含 SYSTEM 角色和 JSON 包装原句）。记录上下文长度和计算成本。已有 P0 运行若满足全部条件可复用，否则不可拿不同配置旧结果当纯 prompt 消融。

同一个 **P1-SFT** checkpoint（按 **dev、k=0、USER_K0** 选定）做三种推理：

1. 无示例 k=0  
2. 随机训练示例 k=3  
3. KNN 训练示例 k=3  

三条件**不**分别训练 adapter。若 P0 可复用，只需 3 个 P1 正式训练 run；否则纯 prompt 对照共 6 个。每个 P1 种子 3 个推理条件。不默认铺开全部 k。

可选：冻结 Instruct（无梯度）先在 **dev** 跑 k=0 / 随机 k=3 / KNN k=3，只做输入与解析诊断。不据此宣称完成 SFT，也不反复查看 Gold。

## KNN 定义与防泄漏

这里的 KNN：按目标原文的向量相似度，检索**训练句及其已确定标签**作为上下文示例。不是 kNN-LM 概率融合，也不是 SpanAnchor 复现。

- 库仅来自合格训练记录，按独特原文建索引。相同文本标签冲突先登记并从示例库排除，不能随意选一个答案。
- 不用 Gold / dev 文本建库，不用其标签选示例。允许 dev/test 原文仅作为**查询**。
- 固定检索编码器与 revision/hash、pooling、归一化、相似度、排序（近到远）、并列 ID 规则、token 预算。不在 Gold 上选编码器或 k。
- 先固定 k=3。若比较 k∈{1,3,5}，只在 **dev 一次性**选择并登记。token 预算内可少于 k，记录实际数量。
- 训练样本若用于检索增强 SFT：排除自身 ID、同原文 / 近重复组，优先排除同来源文档；训练阶段不能用当前目标标签做检索排序。
- 推理跨集合重复依现有审计处理，保留已批准的句级划分属性，不改称文档隔离。
- 随机控制：固定 query ID + 种子，按 KNN 示例长度档匹配；不得按查询答案匹配。与 KNN 的 k、预算相同，报告实际 token 差异。
- 日志：query ID、示例 ID / 文本哈希、标签版本、相似度、排名、实际 k、token 数。实例偏移只相对实例 `text`，不可拷贝给目标文本。

磁盘上旧 `knn_index/` **不是**本设计的官方索引，不得直接复用其 F1（本来也没有正式 F1）。

## 可选第二阶段：检索感知 SFT

仅在第一阶段诊断后**另行批准**。对每个训练目标按 leave-group-out 提供 0 或 3 个示例，预先固定无示例比例（候选 50%，不是已验证最优）。只监督目标答案。该条件改变训练输入，需要新 adapter，不能与「只在推理加示例」混称同一方法。若要归因训练期检索，还需长度匹配随机示例的训练控制；**不是**本轮默认扩展。

## 偏移协议：先保留，必要时单独改

P1 仍输出 `start/end/type`，保持现有评分链。输出前「检查偏移」不能保证字符数正确。  
在 **dev** 统计 JSON 解析、越界/重叠、类型混淆、边界/定位错误及原始预测切片。合法切片不证明语义正确。失败样本保留原始输出，不删除。

若有证据表明直接计数是主要障碍，可**另测** `text + occurrence + type`，由确定性精确匹配还原偏移。训练 target 必须从已有 start/end 无损转换并全量 round-trip。同短语按全部精确出现位置计数。不存在或序号越界显式失败，不做模糊匹配。这是输出表示消融，**不能**与 prompt / KNN 同时变动再归因 KNN，也不默认执行。

## 评测与停止

主指标 typed exact micro-F1；同时报 P/R、relaxed、K/S/T/L、空标误报、解析失败、截断、耗时与 token。三种子样本 SD 不是测试集 CI。无偏移的文本级指标只诊断。  
开发标签是 Silver 来源，dev 提升不保证人工 Gold 提升。先在 dev 冻结全部配置，再作 Gold150 整体和 Audit-50 / Challenge-100 分项终评；保留全部 run，不挑最优种子。不与历史 2601 的 0.1724 作同口径增益比较。  
没有保证提升或预定目标 F1。不为投稿工作量默认追加全部网格：先 P1-SFT，再同 checkpoint 的随机 / KNN 推理。
