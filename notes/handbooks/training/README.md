# 编码员培训

本目录用于Chinese-SkillSpan的L/K/S/T跨度标注培训。材料依据中文人工编码本 **B.sop_v4.2.14** 整理，包含编码步骤、既往裁决案例及独立编码试测流程。

| 材料 | 内容 |
|---|---|
| [中文完整编码本](../handbook_B_sop_v4.md) | 类别、范围、边界及R08–R23补充规则 |
| [中文Word编码本](../Chinese_SkillSpan_中文版编码簿_v4.2.14.docx) | 可下载的完整手册 |
| [培训流程](protocol.md) | 人员准备、练习、独立编码、原始导出与仲裁 |
| [编码经验与32个案例](cases.md) | 有出处的例句、片段和相应处理 |
| [案例清单](examples.json) | 原文、字符偏移、规则来源及案例类型 |
| [培训登记空表](training_record.csv) | 编码员代号、经验、培训用时和执行状态 |
| [疑问与规则澄清空表](clarification_log.csv) | 问题、适用规则、解释及版本变化 |
| [版本与文件清单](manifest.json) | 手册固定提交及本目录文件校验值 |

## 使用范围与记录状态

材料整理于2026年9月26日。作者报告正在开展编码员培训；具体培训时长、参与者记录、新试测样本和两份独立标签尚未提交到本目录。这里公开的是培训内容和执行流程，没有新增一致性结果。

32个案例均出自手册，包含完整历史句子和带语境条件的短片段。完整案例应从正式盲编样本中排除；短片段用于辅助核查，不能据此排除所有包含同一常见词的新句子。案例清单不是新的测试集。

本轮使用v4.2.14人工规则。v4.2.12机器提示词、手册C及较早的重叠附录保留各自历史用途，不作为新规则版本。培训中发现需要澄清的问题应登记，并在正式编码开始前向两位编码员提供同一说明。

既往15句检查采用机器编码建议，属于机器辅助双人审核；早期50句原文独立编码另行报告。其结果与计算说明见[一致性记录](../../../reproduction/agreement/README.md)。
