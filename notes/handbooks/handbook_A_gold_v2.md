## 标签（平坦，不重叠、不嵌套）

| 标签 | 含义（Gold / goldstyle 操作义） | 例 |
|---|---|---|
| L | 语种词 | 英语、普通话、英文读写能力 |
| K | 学历、专业、证书、领域知识 | 计算机专业、**大学英语六级 / CET-6** |
| S | 可执行技能、方法、工具、经验活动 | 网络管理、Python、飞控计算机 |
| T | 软技能、特质 | 沟通能力、责任心 |

历史差异（脚注即可）：银标 API 把语言**证书**归 **L**（few-shot：`CET-6`→L）。Gold-style 与 Gold v2 操作义把证书归 **K**。手册 B v4.2 已把语言考试改回 **L**（ESCO 独立语言支）。**不要用新规则去改 Gold 文件。**

## 跨度（Gold-length）

1. 标 **完整名词短语**，典型约 4–12 token（Gold 中位 4、均值约 4.9）。  
2. 禁止词中切断（`支持服`）。不要把整段「负责…协助…」收成一条 S。  
3. 同一 NP 内的并列修饰可包在一起（维护和支持服务）；独立技能分开（英语 / Python / 沟通能力）。  
4. 必须是句中**连续原文**。  
5. 只标对候选人的能力要求。报名/体检/公示/福利/班次/纯地点 → **空句**。  
6. 熟悉/掌握 + 工具语言办公软件，Gold-style 训练改写里归 **S**；学历专业证书归 **K**。
